Step 1: Start Apache and MySQL in XAMPP

Database Setup (Using phpMyAdmin + SQL)

Open XAMPP and start Apache and MySQL.
Open your browser and go to:
http://localhost/phpmyadmin
Log in with root user (usually no password, or the password you set).
Go to the SQL tab.
Copy and paste the following queries one by one, then click Go after each:



SQL-- Step 1: Create the database
CREATE DATABASE IF NOT EXISTS my_project_db 
    CHARACTER SET utf8mb4 
    COLLATE utf8mb4_unicode_ci;

-- Step 2: Create the user
CREATE USER 'my_admin'@'localhost' 
    IDENTIFIED BY 'BnZ@200096';

-- Step 3: Grant full privileges to the user
GRANT ALL PRIVILEGES ON my_project_db.* 
    TO 'my_admin'@'localhost' 
    WITH GRANT OPTION;

-- Step 4: Apply the changes
FLUSH PRIVILEGES;

-- Step 5: Verify privileges (Optional - should show full access)
SHOW GRANTS FOR 'my_admin'@'localhost';
After Database Creation:


'''

Open your Laravel project folder and edit the .env file. Update the database settings as follows:

envDB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=my_project_db
DB_USERNAME=my_admin
DB_PASSWORD=BnZ@200096

Save the .env file.
Clear Laravel configuration cache by running these commands in the project terminal:

Bashphp artisan config:clear
php artisan cache:clear

Restart XAMPP (stop and start Apache + MySQL) for safety.
Refresh your application in the browser. The installer should now connect successfully.

VISITOR IMAGE NOT SHOWING (IMPORTANT for Hostinger / shared hosting):

1) In .env set APP_URL with full path including /public if your site uses it:

APP_URL=https://your-domain.com/public

Example for this project:
APP_URL=https://navajowhite-dugong-285103.hostingersite.com/public

2) Create folder (if missing) and make it writable:
   public/uploads
   chmod 755 public/uploads   (Linux/Hostinger)

3) Optional: create storage link for old images
   php artisan storage:link
   OR on Hostinger file manager: make sure public/storage points to storage/app/public
   OR copy storage/app/public/* into public/storage/

4) Clear cache:
   php artisan config:clear
   php artisan cache:clear

5) New visitor photos are saved in: public/uploads/{media_id}/filename
   They open as: {APP_URL}/uploads/{media_id}/filename

6) On Admin > Visitors > Add Visitor you can:
   - Browse File  OR
   - Capture from Camera
