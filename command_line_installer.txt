-----------------------------------------------------------
IMPORTANT: vendor folder is NOT on GitHub (normal for Laravel)

The folder:
  codecanyon-24643230-visitor-pass-management-system\vendor

is listed in .gitignore, so git clone will not include it.

On FIRST START.bat after clone:
  - PC needs internet
  - the launcher downloads Composer and runs "composer install"
  - this can take several minutes (creates vendor automatically)

If vendor install fails:
  1) Check internet / firewall
  2) Run START.bat again
  3) Or copy the whole "vendor" folder from a PC where the app already works
     into: codecanyon-24643230-visitor-pass-management-system\vendor

Manual install (optional, same result):
  cd codecanyon-24643230-visitor-pass-management-system
  ..\php\php.exe ..\runtime\composer.phar install --no-dev
  (composer.phar is auto-downloaded on first START.bat)

Useful commands later:

cd /d %USERPROFILE%\Desktop\s-ib_visitor_pass_management
START.bat
STOP.bat
